## 💼 核心业务落地场景

在企业级 HRMS（人力资源管理系统）的实施交付与数字化转型过程中，“脏数据”往往是导致系统上线延期、频繁报错的首要元凶。本项目不仅是一个 Python 数据处理脚本，更是专为解决**复杂 HR 业务落地场景**打造的数据治理与质检引擎。

### 场景一：新系统上线前的数据迁移与“开荒”
* **现实痛点**：当企业花重金购买了全新的 HCM 系统并准备上线时，最让人崩溃的往往是“历史数据迁移”。HR 导出的存量 Excel 花名册往往**格式群魔乱舞**：手机号中间带空格、身份证号少一位、入职日期有人写 `2023-01-01` 有人写 `2023/1/1`，甚至有人填 `去年一月`。这些“脏数据”若直接导入，会导致新系统瞬间疯狂报错、崩溃罢工。人工清洗几万条数据堪比大海捞针。
* **本系统解决方案**：作为数据入库前的**“全自动洗车机”**。通过 `clean.py` 引擎，系统全自动扫雷，批量执行日期标准化、手机号/身份证脱水去噪、空值智能填充等操作。将非标的乱码瞬间转化为干干净净的“标准件”，彻底抹平手工记录带来的格式差异，保障新系统**数据零误差平滑上线**。

### 场景二：核心花名册的“逻辑测谎”与合规治理
* **现实痛点**：单列数据看着没问题，连起来看却极其离谱。由于历史登记失误，员工花名册中常隐藏深度的**业务逻辑互相打架**现象。例如：“员工状态明明白白写着‘在职’，但后面竟然填了‘离职日期’”；或者“身份证号码推算是 1990 年出生，但‘年龄’那一列写着 20 岁”。
* **本系统解决方案**：这是本工具的核心护城河——**高阶业务“测谎”（跨字段交叉校验）**。引擎懂 HR 的规矩，不仅仅是查单列格式，而是自动比对多列数据的逻辑自洽性。一旦发现逻辑冲突，系统不会粗暴删除，而是通过预设的 `Labeling System` 精准打上异常标签，直接退回给 HR 确认。实现柔性且严谨的自动化逻辑治理。

### 场景三：为高阶 BI 数据看板铺路（数据资产沉淀）
* **现实痛点**：企业高管希望看到精准的人力成本与人效分析看板（Dashboard），但由于底层部门名称、职级命名存在诸多“同义不同字”的情况，导致 BI 工具生成的图表类别错乱，毫无决策参考价值。
* **本系统解决方案**：通过本工具箱的前置清洗与规整，确保所有维度表（如部门、职级、岗位）的数据口径 100% 统一。**让垃圾数据不再污染分析模型**，为后续的 AI 人力资源盘点、高管 BI 驾驶舱提供绝对纯净、可信度高的数据源头。

## ✨ 核心亮点 (Key Features)

* **📊 零破坏资产探测**：在不污染源数据的前提下，宏观扫描数据集规模，全自动化输出各维度缺失值（`NaN`）分布报告，为制定清洗规则提供直观依据。
* **🧹 智能文本去噪机制**：
  * 全局剔除整列全空的无效字段，自动完成文本字段首尾空格修剪。
  * 利用正则表达式（`\s+`）深度清除姓名中间的异常空格（防止后续模糊查询失效）。
  * 阻断并统一清洗历史遗留脏数据（如：将无效输入 `3`、`未知` 自动转化为标准的 `None`/`Null`）。
* **⏳ 时间戳强转与阻断**：对“参加工作时间”、“入职日期”等高频关键时间节点进行标准化转换，对恶性格式进行 `coerce` 阻断打标，防止写库报错。
* **🔍 增量问题打标机制 (Labeling System)**：首创“数据问题”动态标签列。对“唯一标识缺失”、“入职日期缺失”、“证件号重复”的异常行进行**增量合并打标**（如：`证件号缺失;入职日期缺失;`），便于直接导出给客户源头修正。
* **🛡️ 基于国标的跨字段勾稽校验 (Cross-Validation)**：
  * **合法性前置过滤**：利用严格正则 `^\d{17}[\dXx]$` 拦截异常证件号。
  * **高精度年龄反推**：动态切片身份证 7~14 位，结合当前系统时间引入闰年权重（`365.25`）动态计算精确年龄。
  * **性别双向交叉验证**：提取身份证第 17 位特征码（奇男偶女），与原有登记性别自动进行比对。一旦发生冲突，秒级打标 `与身份证不符`，拦截隐蔽逻辑错误。

## 📂 模块详解 (Modules)

### 1. 数据探测器 `explore.py`
快速建立对原始数据集的“第一直觉”。通过跳过填表说明行（`skiprows`），直接透视底层数据矩阵的健康度。

### 2. 核心清洗引擎 `clean.py`
执行标准的数据清洗动作。通过构建增量字符串，将分散在不同维度的致命数据缺陷（如关键ID重复、缺失）浓缩在单一的 `数据问题` 列中。

### 3. 深度业务校验器 `add_age.py`
将技术与行业业务规则深度结合。利用中国居民身份证编码规范，反哺业务系统，自动完成数据富化（新增年龄列并调整至最优视觉字段顺序）与合规性拦截。
